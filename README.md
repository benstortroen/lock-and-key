# Lock and Key Design

# Game Mechanic: 
You carry around a keychain with dangling keys in a labyrinth of doors. You have
to manually slot in every key you use. The feel of the game is more tactile than
a regular item use in a menu. You will fumble through your keys like a campy 
horror movie character being chased in a haunted mansion. My game's
iteraction mechanic opens up doors for puzzles with an emphasis on perspective, 
orientation, and quick thinking.
